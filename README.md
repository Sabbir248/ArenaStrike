# ArenaStrike

Real-time multiplayer tactical 3D battleground web game.

## Project structure

- `backend/` - Spring Boot API, STOMP/WebSocket endpoint, and persistence layer.
- `frontend/` - HTML5/JavaScript client and Three.js rendering boundary.
- `assets/models/` - supplied GLB game models.

## Project Run Guide (কীভাবে প্রজেক্টটি নিজে নিজে রান করবেন)

প্রজেক্টটি সফলভাবে রান করার জন্য আপনাকে **ব্যাকএন্ড (Java Spring Boot)** এবং **ফ্রন্টএন্ড (HTML/JS)** দুটো সার্ভারই চালু করতে হবে। নিচে ধাপে ধাপে গাইডলাইন দেওয়া হলো:

### ধাপ ১: ডেটাবেস (MySQL) চালু করা
১. আপনার **XAMPP Control Panel** ওপেন করুন।
২. **Apache** এবং **MySQL** মডিউল দুটোর পাশে থাকা "Start" বাটনে ক্লিক করে চালু করুন।
৩. ব্রাউজারে `http://localhost/phpmyadmin` এ যান এবং `arenastrike` নামে একটি নতুন ডেটাবেস তৈরি করুন (যদি আগে থেকে তৈরি করা না থাকে)।

### ধাপ ২: ব্যাকএন্ড সার্ভার চালু করা (Spring Boot)
ব্যাকএন্ড সার্ভারটি মূলত গেমের লজিক এবং মাল্টিপ্লেয়ার কানেকশন (WebSocket) নিয়ন্ত্রণ করে।
১. VS Code, IntelliJ IDEA বা যেকোনো টার্মিনাল/কমান্ড প্রম্পট (cmd) ওপেন করুন।
২. টার্মিনালে প্রজেক্টের `backend` ফোল্ডারে প্রবেশ করুন:
   ```bash
   cd E:\XAMPP\htdocs\ArenaStrike\backend
   ```
৩. এবার নিচের কমান্ডটি লিখে এন্টার চাপুন:
   ```bash
   .\gradlew bootRun
   ```
   *(প্রথমবার রান হতে একটু সময় নিতে পারে। টার্মিনালে `Started ArenaStrikeApplication` লেখা আসলে বুঝবেন ব্যাকএন্ড সফলভাবে চালু হয়েছে এবং `8080` পোর্টে রান করছে।)*

### ধাপ ৩: গেম খেলা বা ফ্রন্টএন্ড ব্রাউজ করা (একই পোর্টে!)
আমি আপনার প্রজেক্টটি এমনভাবে কনফিগার করে দিয়েছি যেন **Spring Boot (8080) নিজেই আপনার ফ্রন্টএন্ড সার্ভার হিসেবে কাজ করে!** আপনাকে আর আলাদা করে XAMPP বা Python সার্ভার চালু করতে হবে না।

১. আপনার পিসি বা ফোনের ব্রাউজার ওপেন করুন।
২. এড্রেস বারে নিচের লিংকটি লিখে এন্টার দিন:
   - যদি আপনি যেই পিসিতে রান করছেন, সেখানেই খেলতে চান:
     ```text
     http://localhost:8080/
     ```
   - যদি আপনি আপনার ফোন বা অন্য কোনো পিসি থেকে খেলতে চান (Local Network), তাহলে আপনার পিসির IP অ্যাড্রেস দিয়ে ব্রাউজ করুন (যেমন):
     ```text
     http://192.168.0.227:8080/
     ```
৩. ব্যাস! আপনার সামনে ArenaStrike এর লবি স্ক্রিন চলে আসবে। 

*(বি.দ্র: আপনার আইপি যদি `192.168.0.227` না হয়ে অন্য কিছু হয়, তবে `ipconfig` (Windows) কমান্ড দিয়ে সঠিক আইপিটি জেনে ওই আইপির পর `:8080/` বসিয়ে ব্রাউজ করবেন।)*

**গেম খেলা শেষে সার্ভার বন্ধ করার নিয়ম:**
- **ব্যাকএন্ড বন্ধ করতে:** যে টার্মিনালে `bootRun` কমান্ড দিয়েছিলেন, সেখানে গিয়ে কীবোর্ডের `Ctrl + C` একসাথে চাপুন।
- **ডেটাবেস বন্ধ করতে:** XAMPP Control Panel থেকে Apache এবং MySQL "Stop" করে দিন।
